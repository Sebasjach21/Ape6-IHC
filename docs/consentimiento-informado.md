## Reglas de anonimización

- Nunca se escribe el nombre real del participante en este repositorio, ni en la hoja de observación, ni en ningún archivo de resultados.
- Todo archivo o celda que identifique a un participante usa solo su código (P1, P2, P3).
- Si se graba la pantalla, el archivo de video se nombra con el código (por ejemplo `P1-sesion.mp4`) y no se publica fuera del equipo.
- Los criterios de exclusión (haber diseñado el prototipo, conocer las seis tareas de antemano, ser menor de edad) se verifican y anotan antes de iniciar la primera tarea.
