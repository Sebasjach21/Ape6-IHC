## Cuestionario SUS (System Usability Scale)

Pedir que el participante responda de 1 (muy en desacuerdo) a 5 (muy de acuerdo).

| # | Ítem | Puntaje (1–5) |
| --- | --- | --- |
| 1 | Creo que usaría esta aplicación con frecuencia. | |
| 2 | Encontré la aplicación innecesariamente compleja. | |
| 3 | Pensé que la aplicación era fácil de usar. | |
| 4 | Creo que necesitaría ayuda de una persona con conocimientos técnicos para usar esta aplicación. | |
| 5 | Encontré que las distintas funciones de la aplicación estaban bien integradas. | |
| 6 | Pensé que había demasiada inconsistencia en esta aplicación. | |
| 7 | Imagino que la mayoría de las personas aprendería a usar esta aplicación muy rápidamente. | |
| 8 | Encontré la aplicación muy incómoda de usar. | |
| 9 | Me sentí muy seguro usando la aplicación. | |
| 10 | Necesité aprender muchas cosas antes de poder usar esta aplicación. | |

**Cálculo del puntaje SUS**

- Ítems impares (1, 3, 5, 7, 9): puntaje − 1.
- Ítems pares (2, 4, 6, 8, 10): 5 − puntaje.
- Sumar los diez valores resultantes y multiplicar por 2,5.
- Resultado en una escala de 0 a 100. Referencia de usabilidad aceptable: 68.
