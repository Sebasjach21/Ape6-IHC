# Guion de la sesión de pilotaje (moderador)

Imprimir o tener a la mano. Cada sesión dura unos 20 minutos.

## Antes de las sesiones

- [ ] 3 participantes que cumplen el perfil y los criterios de exclusión (estudiantes UTA, mayores de edad, no del grupo, sin conocer las tareas)
- [ ] Prototipo abierto y en estado inicial; internet probado
- [ ] Cronómetro: **una sola persona** (Julio) y una hoja por participante
- [ ] Consentimiento, tareas y pista escrita a la mano del moderador
- [ ] **Ensayo interno:** un integrante hace todas las tareas (no cuenta como dato) y se prueba el reinicio

## Durante cada sesión

| Paso | Qué se hace o se dice |
| --- | --- |
| 1. Bienvenida | «Vamos a probar una aplicación, no a evaluarte a ti.» |
| 2. Consentimiento | Leer el texto de `Consentimiento_Informado.md`. Preguntar si acepta participar y si acepta que se grabe solo la pantalla |
| 3. Perfil | Anotar edad, carrera y si conoce el prototipo. Si no cumple el perfil, no se registra como participante |
| 4. Voz alta | «Mientras trabajas, di en voz alta lo que piensas, lo que buscas y lo que te sorprende.» |
| 5. Tareas | Leer cada tarea tal cual. El cronómetro arranca al terminar de leer y se detiene cuando el usuario termina o abandona |
| 6. SUS | El participante lo responde solo, sin que nadie mire |
| 7. Cierre | «¿Qué fue lo más confuso? ¿Qué funcionó mejor?» y agradecer sin comentar su desempeño |

## Las seis tareas (leer textual)

| Tarea | Consigna | Meta / Máx (s) |
| --- | --- | --- |
| T1 | ¿Qué productos ofrece el menú de hoy? | 60 / 120 |
| T2 | Agrega un café americano a tu pedido. | 60 / 120 |
| T3 | Agrega también una empanada de pollo. | 60 / 120 |
| T4 | Escribe tu nombre, elige una hora de retiro, confirma tu pedido y dime tu número de pedido. | 90 / 180 |
| T5 | Cambia la hora de retiro de tu pedido confirmado a las 12:00. | 90 / 180 |
| T6 | Ya no quieres este pedido. Cancélalo y confirma que quedó cancelado. | 60 / 120 |

## Lo que el moderador puede y no puede decir

- **Puede:** «¿Qué estás pensando?» (no es pista) · la **pista única**, una vez por tarea, leída textual (se registra «Con ayuda»): «Vuelve a leer la tarea y revisa las opciones que tienes en pantalla» · «Gracias, pasemos a la siguiente» al llegar al tiempo máximo (se registra «No»).
- **No puede:** nombrar botones o pantallas, decir «casi», «por ahí» o «muy bien», señalar la pantalla ni corregir una respuesta.

## Entre participantes

Detener la grabación, reiniciar el prototipo (recargar `cafeu-v3.html`) y comprobar el estado inicial antes de recibir al siguiente participante.
